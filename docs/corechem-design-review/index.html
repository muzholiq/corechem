CORECHEM · MULTI-PERSONA REVIEW

멋진 소재 브랜드에서,
믿을 수 있는 트레이딩 회사로.

아트디렉터, 화학 트레이딩 사업 담당자, 모바일 UX 엔지니어가 현재 시안을 독립 검수하고 의견을 비교했습니다. 결론은 디자인을 버리는 것이 아니라, 거래의 근거를 더 정확하게 압축하는 것입니다.

최종 판정

산업 재료 견본책이라는 시각 콘셉트는 차별화에 성공했습니다. 그러나 지금은 제조사 또는 디자인 스튜디오처럼 보일 가능성이 큽니다. 트레이딩 회사임을 말해주는 역할·신뢰·문의 동선을 최소한으로 보강해야 합니다.

가벼운 정적 구조

외부 프레임워크가 없어 빠르고, 한·영·일 화면도 안정적입니다.

확인된 로고 적용 방향

기존의 굵은 지구본+CC 심볼은 유지하고, 심볼을 왼쪽에 두고 CoreChem / TRADING 워드마크를 오른쪽에 쌓는 가로형 조합을 헤더에 적용했습니다. 로고가 확인되어 브랜드 고유성 점수를 5.8에서 6.8로 보정했습니다.

심볼 자체는 글로벌 트레이딩의 의미가 명확하지만 작은 화면에서는 내부 선이 조밀합니다. 헤더에서는 최소 30px 이상의 심볼 크기를 유지하고, 향후 원본 벡터 파일을 받으면 PNG를 SVG로 교체하는 것이 좋습니다.

가장 큰 문제와 개선

P0

회사 역할이 모호합니다

“찾고 연결합니다”만으로는 브로커인지, 조달·유통·수입을 책임지는 회사인지 알 수 없습니다.

개선: 실제 업무 범위를 확인한 뒤 ‘선정·조달·공급’ 중 사실인 동사만 Hero에 사용합니다.

P0

서로 다른 제품 카드가 모두 같은 PTFE 예시로 갑니다

코팅·수지·용제·첨가제를 눌러도 같은 내용이 보여 정보 구조와 신뢰가 무너집니다.

개선: 실제 상세가 생기기 전에는 카드 링크를 없애고 ‘이 분야 문의’로 바꿉니다.

P0

트레이딩 회사의 최소 신뢰 근거가 없습니다

회사명만 있고 법적 거래 주체, 소재지, 실제 연락처, 문서 대응 여부를 확인할 수 없습니다.

개선: 푸터 법인 정보 + TDS/SDS 문의 안내 한 줄만 넣습니다. 긴 인증 섹션은 필요 없습니다.

P1

사선 SAMPLE 그래픽이 임시 템플릿처럼 보입니다

시각적으로 강하지만 실제 제품이나 공급 역량을 증명하지 못합니다.

개선: 실제 소재 매크로 사진 1장, 포장·공정 사진 또는 정교한 기술 일러스트로 교체합니다.

P1

제품 분류 기준이 섞여 있습니다

완제품, 소재, 범용 화학군이 한 레벨에 있어 전문 포트폴리오처럼 읽히지 않습니다.

개선: 실제 제품표를 받은 뒤 ‘화학군’ 또는 ‘적용 산업’ 한 축으로 통일합니다.

P1

모바일 헤더와 언어 선택이 빽빽합니다

특히 일본어에서 로고·문의·KO/EN/JA가 한 줄에 몰립니다. 390px 이하와 글자 확대에서 취약합니다.

개선: 첫 줄은 로고와 문의, 언어 선택은 작은 두 번째 줄 또는 메뉴 안으로 분리합니다.

P1

접근성 기본 장치가 빠졌습니다

키보드 포커스 표시, 44px 언어 버튼, 앵커 상단 여백, 모션 감소 설정이 없습니다.

개선: focus-visible, 터치 영역, scroll-margin, prefers-reduced-motion을 추가합니다.

P2

다국어 SEO는 아직 한글 단일 문서입니다

화면은 번역되지만 검색엔진이 언어별 페이지로 이해하기 어렵습니다.

개선: 배포 전에 /ko, /en, /ja 주소와 언어별 title·description·hreflang을 만듭니다.

권장 최종 구조

01 / HERO

정체성

무엇을 누구에게 어떻게 공급하는지 한 문장으로 말합니다.

02 / PRODUCTS

취급 분야

동일한 분류 기준의 3~4개 제품군과 분야별 문의를 둡니다.

03 / PROCESS

거래 역할

요구 확인 → 제품 소싱·검토 → 공급 연결의 짧은 3단입니다.

04 / PROOF

최소 신뢰

법인 정보, 실제 연락처, TDS/SDS 안내를 한 줄 띠로 압축합니다.

05 / PARTNERS

제조사 접점

한국 시장 파트너십 문의를 짧게 분리합니다.

06 / CONTACT

실제 행동

전화·이메일을 바로 실행하고 제품명 또는 용도만 받습니다.
