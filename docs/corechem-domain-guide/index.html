법인 설립 전 입력 방법

등록인 유형은 개인

.com, .kr, .co.kr 모두 현재 개인 명의로 등록할 수 있습니다. .kr 계열은 대한민국 주소지가 필요합니다.

실제 본인 정보 사용

등록인 이름은 본명, 주소는 실제 국내 주소, 이메일과 전화번호는 본인이 계속 관리할 정보를 넣습니다.

아직 없는 법인은 쓰지 않기

존재하지 않는 ‘주식회사 코어켐’이나 임의 사업자번호를 입력하지 않습니다. 회사·기관명은 비워두거나 개인으로 선택합니다.

보안 즉시 설정

자동 갱신, 2단계 인증, 도메인 잠금을 켜고 결제카드 만료와 책임자 이메일을 주기적으로 확인합니다.

법인이 생긴 다음

법인 계정 만들기

법인명, 사업자등록번호, 회사 관리 이메일로 등록기관 계정을 만듭니다.

소유권 이전 신청

현재 개인이 양도인, 새 법인이 양수인이 되어 등록기관의 소유권 이전 절차를 진행합니다.

증빙과 비용 확인

본인 인증과 사업자등록증 등이 필요할 수 있고, 등록기관에 따라 이전과 1년 연장 비용이 발생할 수 있습니다.

회사 자산으로 관리

법인 명의 이전 후 회사 이메일, 자동 갱신, DNSSEC과 관리 담당자를 다시 확인합니다.

상표와 혼동 위험

도메인이 비어 있어도 상표 사용이 안전하다는 뜻은 아닙니다.

미국, 호주, 중국에 Corechem이라는 화학 관련 기업이 이미 활동하고 있습니다. 해외 거래 전에 KIPRIS와 주요 수출국 상표 검색을 별도로 진행하고, 가능하면 국가나 거래 성격이 드러나는 도메인을 사용합니다.
